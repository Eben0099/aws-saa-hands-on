# aws-saa-hands-on

Hands-on projects for my AWS Certified Solutions Architect Associate (SAA-C03) preparation.

## About me

I am a backend and cloud engineer based in Yaoundé, Cameroon. I am moving toward Cloud and MLOps roles.

## Goal of this repository

Each project is a small lab built in a real AWS account. Every project documents what I built, what I decided and why, what went wrong, and what it cost.

The repository will contain 14 projects: `projet-01` to `projet-08`, then `projet-m1` to `projet-m6`.
